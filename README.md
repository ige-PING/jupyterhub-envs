# jupyterhub-envs
A repo to host IGE environments that are available on the jupyterhub

Three default environments are currently available on IGE jupyterhub :
 - pangeo-notebook based on [the docker image provided by PANGEO](https://github.com/ige-PING/pangeo-docker-images/tree/master/pangeo-notebook)
 - pangeo-pytorch based on [the docker image provided by PANGEO](https://github.com/ige-PING/pangeo-docker-images/tree/master/pytorch-notebook)
 - pangeo-tfjax (tensorflow + jax) based on [the docker image provided by PANGEO](https://github.com/ige-PING/pangeo-docker-images/tree/master/ml-notebook)
